# Benchmark2 — документация проекта

Единая точка знаний по независимому бенчмарку кириллического OCR.
Дата состояния: **2026-11-23**.

## Состояние одной строкой

Установка, клонирование окружения, загрузка моделей и подготовка 17 реальных ROI завершены.
Все шесть движков проходят технические smoke-тесты. Полный прогон **306 операций**
(6 моделей × 17 ячеек × 3 прохода) ещё **не запускался**; каталог `results/` пуст.

## Главное, что нельзя забывать

1. Родительский проект `C:\Work\Projects\Prj_18_OCR_2` и его `.venv` — **только чтение**.
2. Новые OCR-библиотеки ставятся **только** в `Benchmark2\.venv`.
3. ROI не масштабируются; исходные JPEG проверяются по SHA256.
4. Эталонные тексты **предварительные**, не утверждены владельцем.
5. Никакие цифры производительности не выдумываются: пока полный прогон не выполнен,
   результатов в миллисекундах нет.
6. Дэшборд слушает фиксированный `http://127.0.0.1:18018/`; переопределение — `BENCHMARK2_PORT`.
7. Windows OCR требует русского языкового пакета и имеет проблему с узкими строками —
   см. [04_MODELS.md](04_MODELS.md#45-windows-ocr-важное-ограничение).
