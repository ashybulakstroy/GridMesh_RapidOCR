# Цена: знак валюты и время пакетного OCR

Дата: 19 ноября 2026. Исходное задание: `5e781cb12b4d487cbe68c031adab0c7b`.

## Что изменено

В поле цены проверяется отдельный Т-образный знак валюты. Если OCR прочитал его как последнюю 7, исправление разрешается только при подтверждении формы символа и количества предшествующих цифровых глифов. Исходный текст сохраняется в `ocr_text`, свидетельство — в `currency_symbol`. Просто удалять последнюю 7 запрещено. Написания ₸, T, Т, тг, тенге уже поддерживаются строгим числовым парсером.

Дополнительного вызова нейросети для валюты нет. Проверяются только подозрительные цены из цифр, заканчивающиеся на 7; обработка делит существующий кооперативный бюджет 5 мс с numeric ROI. После исчерпания бюджета новые проверки не запускаются. Один синхронный вызов OpenCV может выйти за границу бюджета; это не жесткий real-time лимит. При недостаточных свидетельствах значение сохраняется без исправления.

Для детекторного fallback многострочных названий используется компактный профиль с минимальным размером входа 160 и восстановлением координат. При пустом ответе применяется прежний детектор. Для числовых ячеек прежний детектор сохранен: ускоренный вариант на данном чеке объединял разные числовые строки.
