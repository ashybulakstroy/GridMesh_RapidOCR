# Модели гонки: идентификация, а НЕ чужие бенчмарки

Маршруты моделей сверять с официальным списком RapidOCR: https://rapidai.github.io/RapidOCRDocs/main/en/model_list/ . Справка для корректного выбора конфигурации, **не источник результатов**.

- PP-OCRv5 `MOBILE`, `cyrillic`: русский текст (baseline).
- PP-OCRv6 `TINY`, `en`: официальная multilingual-rec модель; нет кириллического маршрута.
- PP-OCRv6 `SMALL`, `en`: официальная multilingual-rec модель; нет кириллического маршрута.
- Опционально сторонняя v6 Tiny с кириллицей: https://huggingface.co/metrika-labs/PP-OCRv6_tiny_rec_cyrillic_onnx, **НЕ подключена по умолчанию**, требуется разрешение на скачивание, понимание словаря/ONNX.

Поиск в документации используется ТОЛЬКО для установления корректного имени модели и API. Не включать примеры чужих latency, точности, FPS, RAM или CPU в отчёт как собственные измерения. Если модель/маршрут в конкретной RapidOCR не поддерживается — честная ошибка, не заменять молча другими весами.

В первом бенчмарке используются заранее размеченные ROI — распознавание текста без text detector, без GridMesh. Это существенно упрощает и ускоряет быстрый отчёт и сохраняет одинаковые условия для моделей. Det-v6 Tiny/Small можно тестировать отдельно после согласования.
