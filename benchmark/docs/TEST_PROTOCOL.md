# Протокол измерения только на ПК владельца

1. Получить оригинальные фото; сверить с эталонами, вручную утвердить сомнительные названия; создать корректные нормализованные ROI по исходным пикселям. SHA256 обязателен.
2. `python -m benchmark validate`: нет моделей, нет inference, нет нагрузки. Не стартовать при `IMAGE_MISSING`, `ANNOTATION_MISSING`, `SHA256_MISMATCH`, отсутствии поля.
3. После отдельного одобрения установить RapidOCR 3.10+, запускать `python -m benchmark run --confirm-load` без фонового планировщика.
4. Для каждой модели отдельно создать recognizer, записать реальное время конструирования и прогрева. Все 5 измеряемых прогонов проходят **на прогретой модели**, не включать время загрузки в warm-runtime.
5. `single_cell`: для каждого поля один отдельный вызов `recognize_txt([crop])`, без pooling, группировки и многопоточности Python. Сумма `cell_ocr_ms` и OCR-loop-wall — разные значения, оба нужны. Также measure full receipt wall.
6. `batch`: точно те же изображения/crops/порядок, вызовы `recognize_txt([crop, ...])` размерами до BATCH_SIZE. Записывать реальный размер, время каждого батча и их сумму.
7. CPU и память измерять локальным инструментом; исходная занятость системы сохраняется в метаданных. Результаты на занятом компьютере не выдавать за абсолютную производительность без пометки `BUSY_HOST`.
8. Сопоставлять `quantity`, `unit_price`, НДС (`printed_quantity`, `printed_unit_price`) и `printed_total` через Decimal. Ненадёжная транскрипция или неподдерживаемая кириллица не оценивается как строгая текстовая точность.
9. Не скрывать ошибки и прерывания. `raw.jsonl` хранит каждую попытку отдельно, CSV/HTML только вычисленные из этих локальных записей. Отчёт до запуска: `NOT_MEASURED`, без вставки цифр извне.
10. Только потом — отдельным запуском, после нового разрешения — sweep настроек потоков и batch. Quick не запускает полную матрицу.

Медиана по 5 измерениям, P95 nearest-rank. Не смешивать холодный старт и работу с прогретой моделью. Сравнение fast/small по кириллице не должно скрывать `UNSUPPORTED_SCRIPT`.
